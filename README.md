# GTA VI — The Leonida Archive

A desktop-first interactive fan portfolio exploring the characters, locations, and atmosphere of Grand Theft Auto VI.

## Run locally

Requires Node.js 20.19+ or 22.12+.

```bash
npm ci
npm run dev
```

To create a production build:

```bash
npm run build
```

The Vite output is written to `dist/`.

## Project

- React 19 and Vite
- Cursor-controlled video hero with scene switching
- Character and location archive with locally stored media
- CSS 3D gallery interactions

This is an unofficial fan-made showcase and is not affiliated with Rockstar Games.
